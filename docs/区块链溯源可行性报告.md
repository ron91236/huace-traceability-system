# 区块链溯源可行性报告

> 调研日期：2026-08-31 ｜ 范围：trace-system（码包/绑定/扫码/防伪全链路）

## 一、结论先行

**推荐采用「关键数据哈希锚定存证」方案，接入成熟的存证/溯源云服务（蚂蚁链可信存证、腾讯云至信链），而非自建联盟链节点或全量上链。**

只需在现有 MySQL 数据流转的关键节点计算 SHA-256 哈希并调用云存证 API，即可获得不可篡改、低成本、可向监管/司法举证的溯源背书。PoC 改造量约 1 个接口 + 1 张存证表，无需引入区块链技术栈。

## 二、现有数据链路梳理（代码结论）

`TracePageService.queryBySerialNo` 溯源详情由四类数据组装：企业信息（Enterprise）、商品（Goods）、证书（EnterpriseCert）、批次检测（Batch 含 testCode/result）；码包实体（CodePackage/Item）承载流水号、防伪码、绑定状态（bindStatus→BOUND）。绑定关系由 `OrderCode` 关联批次/码包，扫码由 `ScanRecord` 记录，防伪验证按 `serialNo + antiFakeCode` 判定并由 `scanCount` 累计。前端 `TraceView.vue` 展示企业、商品、证书、检测报告、基地、防伪验证、IoT/视频/轨迹等模块。

关键点：**所有溯源数据均来自 MySQL/MongoDB 中心化存储，无任何防篡改机制**，这正是上链价值所在。

## 三、方案对比（网络调研）

| 方案 | 接入方式 | 费用 | 延迟 | 合规认可 | 集成量 |
|---|---|---|---|---|---|
| 蚂蚁链可信存证/溯源 | 云 API 提交哈希，多存证司法链背书 | 按次/按量，小规模可包年 | 秒级返回 | 高（司法链认可） | 低 |
| 腾讯云至信链 | 云 API Hash 存证 | 按次/按量 | 秒级 | 高 | 低 |
| FISCO BCOS | 自建/托管联盟链节点 | 服务器+运维，隐性成本高 | 秒级 | 中 | 高 |
| 长安链 ChainMaker | 自建节点或链引擎托管 | 节点运维成本 | 秒级 | 高 | 高 |

自建联盟链（FISCO、长安链）虽开源，但需自维节点、共识网络、监控与密钥管理，小团队无区块链经验下运维风险高、隐性成本大，PoC 阶段不划算。

## 四、存证点与 PoC 设计

**值得上链的数据（哈希锚定，不含明文/图片）：**

1. 码包创建（CodePackage）——批量生成规则 + 数量 + 生成者；
2. 批次创建及检测报告（Batch.testCode/testResult/testOrg/testTime 的哈希）；
3. 企业证书（EnterpriseCert.certNo/起止日期）注册与作废；
4. **绑定事件**（OrderCode→CodePackageItem 的 BOUND 关系，含时间戳）——溯源链核心；
5. 防伪验证结果哈希——按批次/按天聚合存证，而非逐次。

**最小 PoC：**

- 新增 1 张 `trace_evidence` 表（业务ID、类型、contentHash、链上 txHash、存证时间、状态）；
- 1 个 `EvidenceService` 接口：`assert(BizType, bizId, contentJson)`，内部做「本地落哈希→调云存证 API→回写 txHash」异步化；
- 在以上 5 个服务写路径插入一行调用。改造量估计 **3~5 人天**，不动 C 端展示逻辑。

## 五、成本与合规

- **成本**：按次存证单价约零点几元至数元，若只存关键事件（码包/批次/证书/绑定），每年几万条量级，年费约 **数千至数万元**；可按量阶梯或包年套餐，远低于自建节点（服务器+运维通常 5~10 万+/年）。
- **合规提示**：无需单独「链上存证资质」，存证本身是技术服务；但对外宣称「司法级效力」须依托有司法链背书的服务（蚂蚁链司法链、至信链）；建议同时保留本地哈希与时间戳（第三方时间戳服务）形成双重证据链。

## 六、风险与不推荐做法

1. **不要自建公链节点**——合规、Gas 成本、性能均不可控。
2. **不要把高频扫码（ScanRecord）逐条上链**——扫码量级巨大，逐条上链成本失控且无必要；应改为按批次/按天聚合哈希存证。
3. **不要全量数据/图片上链**——图片体积大、含隐私，应只上哈希。
4. **注意异步化**——存证 API 延迟与失败需异步重试，避免阻塞现有同步链路（借鉴 `ScanRecord` 的「非阻塞 try-catch」思路）。
5. **密钥安全**——云存证 AK/SK 需独立保管，避免与业务库同机泄露。

## 七、落地前置条件（下一步行动）

- 注册云存证服务账号（蚂蚁链/至信链）并获取 AK/SK；
- 确认按量计费或包年套餐价格；
- 账号就绪后即可实施「先做本地部分」：`trace_evidence` 表 + `EvidenceService` 本地哈希，云 API 留接口待接入。
