# 模板体系重构 P4（静态落地页 + 侧边栏外链）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消费者扫码先进一个静态落地页（企业填的富文本/视频/宣传图 + 系统实时防伪区），右侧常驻按钮栏可跳溯源详情或企业自己的外链（微博、公众号二维码等）。

**Architecture:** 沿用 P2 定下的分工——模板定骨架（`config_json.landingBlocks` / `sideMenu` / `gates`，管理端唯一写入方），企业填内容与外链（`trace_landing_content` 按 block_key 存内容，`enterprise_side_link` 存外链）。骨架解析继续长在 `TemplateConfigReader` 上；授权继续走 `TemplateGrantGuard.requireGranted(..., LANDING)`。消费者端新增免登录聚合接口 `GET /api/trace/landing/{sn}` 与 `/s/:sn` 路由，非落地页模板或企业全空时 302 回 `/trace/{sn}`。

**Tech Stack:** Spring Boot 3.2.5 + MyBatis-Plus 3.5.6 + JUnit 5/Mockito（STRICT_STUBS）；Vue 3 `<script setup lang="ts">` + Element Plus + sortablejs + Tiptap（`RichTextEditor`）。

**Spec:** `docs/superpowers/specs/2026-10-23-模板体系重构-design.md` §3/§5/§6.2/§6.3/§7/§8/§9.1/§9.2/§10/§12/§13。

**本轮没有数据库迁移**：`trace_landing_content`、`enterprise_side_link` 两张表 V27 已经建好（`sql/V27__template_grant_foundation.sql`），落地页模板行由管理端 UI 创建，不需要 SQL。

### 2. 后端四个反复咬人的点

| 坑 | 规则 |
|---|---|
| `BusinessException` 经 `GlobalExceptionHandler` 仍是 HTTP 200，body 是 `{"code":500,"msg":...}` | MockMvc 断言必须打 `jsonPath("$.code")`，`status()` 永远绿 |

### 4. 两个 P3 学到的教训，P4 更容易犯

- **`watch(..., { immediate: true })` 里读到的 `const` 必须在它上面已经声明**。immediate 回调在 setup 里当场执行，读到后面才声明的 computed 就是 `ReferenceError: Cannot access before initialization` → 消费者页白屏，而 `vue-tsc` **抓不到**（它只在同作用域静态可判时报错）。
- **内置浏览器 `visibilityState=hidden` 时 Vue `<Transition>` 被冻结**，DOM 里会留下"弹窗没关/同一列两个 el-tag"的假象；截图工具会直接报错。落地页大量用类切换（`expanded`/`hidden`），断言前先确认页面可见，或只断言类名与数据，不断言动画结果。

### 5. 生产数据现状（决定怎么验）

- 5 个 BOUND 码分属福鹿家(23)、绿源唯品(40)、宠优佳(19)，三家真实企业的企业端密码都不是统一测试密码。

```java
    /** 落地页的固定区块枚举（spec §5：key 不新生成，骨架只决定哪些块存在） */
    public static final List<String> LANDING_BLOCK_KEYS = List.of("richtext", "video", "promoImages", "antiFake");
    /** 侧边栏显示形态：float=带把手可收起，inline=常驻直显（参考页的 is_show_menu 0/1） */
    public static final List<String> SIDE_MENU_DISPLAYS = List.of("float", "inline");

    /** 模板定义的一个落地页区块 */
    public record LandingBlockDef(String key, String name, int sortOrder, boolean enabled) {}

    /** 落地页区块骨架，按 sortOrder 升序；非 landing 模板返回空列表 */
    public List<LandingBlockDef> landingBlocksOf(String configJson) {
        if (!isLanding(configJson)) return List.of();
        List<LandingBlockDef> defs = new ArrayList<>();
        for (Map<String, Object> row : rawList(configJson, "landingBlocks")) {
            String key = trimmed(row.get("key"));
            // 不在枚举里的 key 一侧都渲染不出来，读的时候直接丢；写入侧由 validate 当场拒绝
            if (key == null || !LANDING_BLOCK_KEYS.contains(key)) continue;
            String name = trimmed(row.get("name"));
            defs.add(new LandingBlockDef(key, name == null ? key : name,
                    intOf(row.get("sortOrder"), defs.size()), boolOf(row.get("enabled"), true)));
        }
        defs.sort(Comparator.comparingInt(LandingBlockDef::sortOrder));
        return defs;
    }

    /**
     * 侧边栏配置。永远返回非 null 并补齐默认值，让上层不必到处 `!= null`——
     * "没配 sideMenu"和"配了但只写了 enabled"是同一个意思：其余项按默认走。
     */
    public Map<String, Object> sideMenuOf(String configJson) {
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("enabled", false);
        out.put("display", "float");
        out.put("showTraceDetail", true);
        out.put("showBottomEntry", true);
        Map<String, Object> cfg = config(configJson);
        if (cfg == null || !(cfg.get("sideMenu") instanceof Map<?, ?> m)) return out;
        Map<String, Object> menu = new LinkedHashMap<>();
        m.forEach((k, v) -> menu.put(String.valueOf(k), v));
        if (menu.containsKey("enabled")) out.put("enabled", boolOf(menu.get("enabled"), false));
        String display = trimmed(menu.get("display"));
        if (display != null && SIDE_MENU_DISPLAYS.contains(display)) out.put("display", display);
        if (menu.containsKey("showTraceDetail")) out.put("showTraceDetail", boolOf(menu.get("showTraceDetail"), true));
        if (menu.containsKey("showBottomEntry")) out.put("showBottomEntry", boolOf(menu.get("showBottomEntry"), true));
        return out;
    }

    /** 闸门配置（目前只有 requireAntiFakeBeforeJump）；没配就是空 Map，取值处用 get(...) 即 null=false */
    public Map<String, Object> gatesOf(String configJson) {
        Map<String, Object> cfg = config(configJson);
        if (cfg == null || !(cfg.get("gates") instanceof Map<?, ?> m)) return Map.of();
        Map<String, Object> out = new LinkedHashMap<>();
        m.forEach((k, v) -> out.put(String.valueOf(k), v));
        return out;
    }
```

```java
    /** longModules 数组的原始行；顺序就是管理端保存时的数组顺序 */
    private List<Map<String, Object>> rawModules(String configJson) {
        return rawList(configJson, "longModules");
    }

    /** 取 config_json 里某个数组键的原始行；缺失、非法或不是数组返回空列表 */
    private List<Map<String, Object>> rawList(String configJson, String field) {
        Map<String, Object> cfg = config(configJson);
        if (cfg == null) return List.of();
        Object v = cfg.get(field);
        if (!(v instanceof List<?> list)) return List.of();
        List<Map<String, Object>> out = new ArrayList<>();
        for (Object o : list) {
            if (!(o instanceof Map<?, ?> m)) continue;
            Map<String, Object> row = new LinkedHashMap<>();
            m.forEach((k, val) -> row.put(String.valueOf(k), val));
            out.add(row);
        }
        return out;
    }
```

```java
    private void validateLandingBlocks(String configJson) {
        List<Map<String, Object>> rows = rawList(configJson, "landingBlocks");
        if (rows.size() > MODULE_MAX) {
            throw new BusinessException("落地页区块最多 " + MODULE_MAX + " 个");
        }
        Set<String> keys = new HashSet<>();
        for (Map<String, Object> row : rows) {
            String key = trimmed(row.get("key"));
            if (key == null) throw new BusinessException("区块缺少标识（key）");
            if (!LANDING_BLOCK_KEYS.contains(key)) {
                throw new BusinessException("不认识的区块：" + key + "，只能是 " + LANDING_BLOCK_KEYS);
            }
            if (!keys.add(key)) throw new BusinessException("区块标识重复：" + key);
            String name = trimmed(row.get("name"));
            if (name != null && name.length() > NAME_MAX) {
                throw new BusinessException("区块名称不能超过 " + NAME_MAX + " 字");
            }
        }
        // display 只有 float/inline 两种语义，写错会让侧边栏落到第三种没人处理的状态
        Map<String, Object> menu = sideMenuOf(configJson);
        if (!SIDE_MENU_DISPLAYS.contains(String.valueOf(menu.get("display")))) {
            throw new BusinessException("侧边栏显示方式只能是 " + SIDE_MENU_DISPLAYS);
        }
    }
```

```java
    /** Jackson 对 JSON 布尔给 Boolean，但也可能是字符串或 0/1 */
    private static boolean boolOf(Object v, boolean fallback) {
        if (v instanceof Boolean b) return b;
        if (v instanceof Number n) return n.intValue() != 0;
        if (v instanceof String s) {
            String t = s.trim();
            if ("true".equalsIgnoreCase(t) || "1".equals(t)) return true;
            if ("false".equalsIgnoreCase(t) || "0".equals(t)) return false;
        }
        return fallback;
```

```java
package com.huace.trace.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.huace.trace.common.BusinessException;
import com.huace.trace.entity.TraceLandingContent;
import com.huace.trace.entity.TraceTemplate;
import com.huace.trace.mapper.TraceLandingContentMapper;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.cache.Cache;
import org.springframework.cache.CacheManager;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * 落地页区块内容：区块骨架归模板（管理端写），内容归企业（本轮由企业写的数据）。
 *
 * <p>行坐标是 (template_id, enterprise_id, block_key)，「企业未填」用**无行**表示，
 * 与长图内容同一套语义（spec §6.2、§12）。antiFake 区块不写行——防伪数据由系统按码实时取，
 * 存一份快照等于给消费者看可能已经过期的结论。
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class LandingContentService {

    /** 单个区块内容长度上限：content 是 MEDIUMTEXT（16MB），这里挡的是异常输入而不是容量 */
    public static final int CONTENT_MAX = 200_000;

    private final TraceLandingContentMapper contentMapper;
    private final ObjectMapper objectMapper;
    private final CacheManager cacheManager;
    /** 放在最后：@RequiredArgsConstructor 的字段顺序就是构造参数顺序，测试手工构造时追加即可 */
    private final TemplateConfigReader configReader;

    /** 企业端列表：模板骨架 ⊕ 该企业已填内容。未填的区块带空串出现，骨架外的历史行忽略 */
    public List<Map<String, Object>> list(TraceTemplate template, Long enterpriseId) {
        Map<String, String> stored = storedContents(template, enterpriseId);
        List<Map<String, Object>> result = new ArrayList<>();
        for (TemplateConfigReader.LandingBlockDef d : skeleton(template)) {
            Map<String, Object> item = new HashMap<>();
            item.put("key", d.key());
            item.put("name", d.name());
            item.put("sortOrder", d.sortOrder());
            item.put("enabled", d.enabled());
            // antiFake 没有内容可填，给空串让前端统一渲染
            item.put("content", "antiFake".equals(d.key()) ? "" : stored.getOrDefault(d.key(), ""));
            result.add(item);
        }
        return result;
    }

    /**
     * 消费者落地页取数：按骨架顺序输出启用的区块与其内容。
     * 未启用的区块整体不出现（管理端关掉了就是不想展示，不是"空着展示"）。
     */
    public List<Map<String, Object>> resolveForLanding(TraceTemplate template, Long enterpriseId) {
        if (enterpriseId == null) return List.of();
        Map<String, String> stored = storedContents(template, enterpriseId);
        List<Map<String, Object>> result = new ArrayList<>();
        for (TemplateConfigReader.LandingBlockDef d : skeleton(template)) {
            if (!d.enabled()) continue;
            Map<String, Object> item = new HashMap<>();
            item.put("key", d.key());
            item.put("name", d.name());
            item.put("enabled", true);
            // antiFake 不带内容：前端拿系统数据渲染现有防伪结论组件，这里塞 null 就是"由系统供给"的标记
            item.put("content", "antiFake".equals(d.key()) ? null : stored.get(d.key()));
            result.add(item);
        }
        return result;
    }

    /** 保存某区块的内容。content 为空即"企业未填"，删行而不是写空串 */
    @Transactional
    public void saveContent(TraceTemplate template, String blockKey, String content, Long enterpriseId) {
        TemplateConfigReader.LandingBlockDef def = skeleton(template).stream()
                .filter(d -> d.key().equals(blockKey))
                .findFirst()
                .orElseThrow(() -> new BusinessException("区块不存在"));

        // 先于任何查库动作拒绝：防伪区块压根没有"内容"这个概念，写进去就是一行永远不会被读的脏数据
        if ("antiFake".equals(def.key())) {
            throw new BusinessException("防伪查询区块由系统按码实时生成，不支持填写内容");
        }

        String value = content == null ? "" : content.trim();
        if ("promoImages".equals(def.key()) && !value.isEmpty()) {
            value = normalizeImageArray(value);
        }
        if (value.length() > CONTENT_MAX) throw new BusinessException("内容过长，请精简后重新提交");

        TraceLandingContent existing = contentMapper.selectOne(new LambdaQueryWrapper<TraceLandingContent>()
                .eq(TraceLandingContent::getTemplateId, template.getId())
                .eq(TraceLandingContent::getEnterpriseId, enterpriseId)
                .eq(TraceLandingContent::getBlockKey, def.key()));

        if (value.isEmpty()) {
            if (existing != null) contentMapper.deleteById(existing.getId());
            evictTracePage();
            return;
        }

        if (existing == null) {
            TraceLandingContent row = new TraceLandingContent();
            row.setTemplateId(template.getId());
            row.setEnterpriseId(enterpriseId);
            row.setBlockKey(def.key());
            row.setContent(value);
            contentMapper.insert(row);
        } else {
            // updateById 的 NOT_NULL 策略对这里的单字段更新正合适：只带 content，其余列不进 SET
            existing.setContent(value);
            contentMapper.updateById(existing);
        }
        evictTracePage();
    }

    /**
     * promoImages 存的是 URL 的 JSON 数组（spec §6.2）。
     * 不是数组就拒：让一个裸字符串混进库里，消费者端每次渲染都要猜它是数组还是单值，
     * 猜错就是把整块宣传图渲染成空白。
     */
    private String normalizeImageArray(String value) {
        List<String> urls;
        try {
            urls = objectMapper.readValue(value, new TypeReference<List<String>>() {});
        } catch (Exception e) {

            log.warn("清除溯源页缓存失败", e);
```

```java
package com.huace.trace.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.huace.trace.common.BusinessException;
import com.huace.trace.entity.EnterpriseSideLink;
import com.huace.trace.mapper.EnterpriseSideLinkMapper;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.ArrayList;
import java.util.List;

/**
 * 企业侧边栏外链：公众号、微博这类按钮的文案、图标与跳转目标。
 *
 * <p>挂企业而非模板（spec 决定 4）——它是企业固有资产，换模板不该丢配置，所以菜单也始终可见。
 * 一条链接要么有 url（点击直接跳），要么只有 image（点击弹二维码），两者都空是死按钮，写入就拒。
 */
@Service
@RequiredArgsConstructor
public class SideLinkService {

    /** 与表字段 VARCHAR(50) 一致 */
    public static final int NAME_MAX = 50;

    private final EnterpriseSideLinkMapper linkMapper;

    /** 企业端列表，含停用项，按 sort_order 升序 */
    public List<EnterpriseSideLink> list(Long enterpriseId) {
        return linkMapper.selectList(new LambdaQueryWrapper<EnterpriseSideLink>()
                .eq(EnterpriseSideLink::getEnterpriseId, enterpriseId)
                .orderByAsc(EnterpriseSideLink::getSortOrder)
                .orderByAsc(EnterpriseSideLink::getId));
    }

    /** 消费者取数：只要启用项，按 sort_order 升序 */
    public List<EnterpriseSideLink> resolveForConsumer(Long enterpriseId) {
        if (enterpriseId == null) return List.of();
        return linkMapper.selectList(new LambdaQueryWrapper<EnterpriseSideLink>()
                .eq(EnterpriseSideLink::getEnterpriseId, enterpriseId)
                .eq(EnterpriseSideLink::getStatus, 1)
                .orderByAsc(EnterpriseSideLink::getSortOrder));
    }

    /** 新建：企业归属与排序由服务端决定，前端不传 */
    @Transactional
    public void create(EnterpriseSideLink form, Long enterpriseId) {
        validate(form);
        Long count = linkMapper.selectCount(new LambdaQueryWrapper<EnterpriseSideLink>()
                .eq(EnterpriseSideLink::getEnterpriseId, enterpriseId));
        form.setId(null);
        form.setEnterpriseId(enterpriseId);
        form.setSortOrder(count == null ? 0 : count.intValue());
        if (form.getStatus() == null) form.setStatus(1);
        linkMapper.insert(form);
    }

    /** 更新：文案/图标/跳转/启停，不允许改归属企业 */
    @Transactional
    public void update(Long id, EnterpriseSideLink form, Long enterpriseId) {
        EnterpriseSideLink existing = owned(id, enterpriseId);
        validate(form);
        form.setId(existing.getId());
        form.setEnterpriseId(enterpriseId);
        form.setSortOrder(existing.getSortOrder());
        // 前端只 PUT 改动字段时 status 是 null，直接落库等于把按钮停用，而接口照样回 200
        if (form.getStatus() == null) form.setStatus(existing.getStatus());
        linkMapper.updateById(form);
    }

    @Transactional
    public void delete(Long id, Long enterpriseId) {
        EnterpriseSideLink existing = owned(id, enterpriseId);
        linkMapper.deleteById(existing.getId());
    }

    /** 拖拽排序：传完整 id 顺序，空列表、重复或任一不属于本企业都整体拒绝 */
    @Transactional
    public void sort(List<Long> ids, Long enterpriseId) {
        if (ids == null || ids.isEmpty()) throw new BusinessException("排序列表不能为空");
        if (ids.stream().distinct().count() != ids.size()) {
            throw new BusinessException("排序列表不能有重复链接");
        }
        List<EnterpriseSideLink> owned = new ArrayList<>();
        for (Long id : ids) owned.add(owned(id, enterpriseId));
        for (int i = 0; i < owned.size(); i++) {
            EnterpriseSideLink patch = new EnterpriseSideLink();
            patch.setId(owned.get(i).getId());
            patch.setSortOrder(i);
            // 只带 sortOrder：url/status 不在 SET 子句里，排序不会顺带改动跳转目标或启停状态
            linkMapper.updateById(patch);
        }
    }

    private EnterpriseSideLink owned(Long id, Long enterpriseId) {
        EnterpriseSideLink existing = linkMapper.selectById(id);
        if (existing == null) throw new BusinessException("链接不存在");
        if (!existing.getEnterpriseId().equals(enterpriseId)) throw new BusinessException("无权限操作");
        return existing;
    }

    private void validate(EnterpriseSideLink form) {
        if (form.getName() == null || form.getName().trim().isEmpty()) {
            throw new BusinessException("按钮名称不能为空");
        }
        String name = form.getName().trim();
        if (name.length() > NAME_MAX) throw new BusinessException("按钮名称不能超过 " + NAME_MAX + " 字");
        form.setName(name);
        String url = form.getUrl() == null ? "" : form.getUrl().trim();
        String image = form.getImage() == null ? "" : form.getImage().trim();
        if (url.isEmpty() && image.isEmpty()) {
            throw new BusinessException("跳转链接与跳转图片至少填一项");
        }
        form.setUrl(url.isEmpty() ? null : url);
        form.setImage(image.isEmpty() ? null : image);
    }
}
```

```java
    /**
     * 消费者落地页取数（免登录）。一次给足 LandingView 需要的东西：
     * 模板骨架（区块/sideMenu/gates）+ 企业内容 + 企业外链 + 详情页目标。
     *
     * <p>模板不是 landing 时不抛错，只回 isLanding=false 加 traceUrl，
     * 由前端 302 到 /trace/{sn}——"落地页模板还没配好"与"这个码本来就不是落地页"
     * 对消费者是同一件事：应该直接看详情。
     */
    public Map<String, Object> queryLanding(String serialNo, HttpServletRequest request) {
        CodePackageItem item = mongoCodeItemService.findBoundBySerialNo(serialNo)
                .map(this::toCodePackageItem)
                .orElseGet(() -> codePackageItemMapper.selectOne(
                        new LambdaQueryWrapper<CodePackageItem>()
                                .eq(CodePackageItem::getSerialNo, serialNo)
                                .eq(CodePackageItem::getBindStatus, "BOUND")));
        if (item == null) throw new BusinessException("该溯源码尚未激活绑定，流水号：" + serialNo);

        Map<String, Object> result = new HashMap<>();
        result.put("serialNo", serialNo);
        result.put("enterpriseId", item.getEnterpriseId());
        result.put("traceUrl", "/trace/" + serialNo);

        TraceTemplate template = templateMapper.selectOne(new LambdaQueryWrapper<TraceTemplate>()
                .eq(TraceTemplate::getTemplateKey, item.getTraceTemplate())
                .eq(TraceTemplate::getStatus, 1));
        String configJson = template == null ? null : template.getConfigJson();
        String mode = configReader.renderModeOf(configJson);
        boolean isLanding = TemplateGrantGuard.LANDING.equals(mode);
        result.put("isLanding", isLanding);
        result.put("renderMode", mode);
        if (template != null) {
            result.put("templateId", template.getId());
            result.put("templateKey", template.getTemplateKey());
            result.put("templateName", template.getTemplateName());
        }
        if (!isLanding) return result;

        result.put("blocks", landingContentService.resolveForLanding(template, item.getEnterpriseId()));
        result.put("sideMenu", configReader.sideMenuOf(configJson));
        result.put("gates", configReader.gatesOf(configJson));
        result.put("sideLinks", sideLinkService.resolveForConsumer(item.getEnterpriseId()));
        // "全空"只看这三项：antiFake 由系统实时供给、从不写内容行，
        // 把它算进来会让"填了富文本但仍判为空"的页被错误地 302 掉（spec §12）
        boolean contentEmpty = ((List<?>) result.get("blocks")).stream()
                .filter(b -> b instanceof Map)
                .map(b -> (Map<?, ?>) b)
                .noneMatch(b -> LANDING_CONTENT_KEYS.contains(String.valueOf(b.get("key")))
                        && b.get("content") != null && !String.valueOf(b.get("content")).isBlank());
        result.put("contentEmpty", contentEmpty);
        return result;
    }
```

```vue
import { ref, computed, watch, nextTick, onMounted, onUnmounted } from 'vue'
import { ElMessage } from 'element-plus'

/** 与后端 TemplateConfigReader.LANDING_BLOCK_KEYS 完全一致；顺序就是默认展示顺序 */
const BLOCK_DEFS = [
  { key: 'antiFake', name: '防伪查询' },
  { key: 'richtext', name: '内容' },
  { key: 'video', name: '宣传视频' },
  { key: 'promoImages', name: '宣传图片' },
]

const props = defineProps<{ modelValue: boolean; templateData: any }>()
const emit = defineEmits<{ 'update:modelValue': [val: boolean]; saved: [] }>()

const saving = ref(false)
const listRef = ref<HTMLElement>()
let sortable: Sortable | null = null

// order 里是 key 数组，代表当前顺序；blocks 记每个 key 的 enabled
const order = ref<string[]>(BLOCK_DEFS.map(b => b.key))
const blocks = ref<Record<string, boolean>>({ antiFake: true, richtext: true, video: false, promoImages: false })
// rest 保存本设计器不负责的那些 config_json 键，保存时原样带回，别顺手洗掉别人的配置
const rest = ref<any>({})
const form = ref<any>({
  templateName: '',
  templateType: '落地页',
  backgroundImage: '',
  sideMenu: { enabled: true, display: 'float', showTraceDetail: true, showBottomEntry: true },
  gates: { requireAntiFakeBeforeJump: false },
})

const orderedBlocks = computed(() => order.value.map(k => ({
  key: k, name: BLOCK_DEFS.find(b => b.key === k)?.name || k, enabled: blocks.value[k] ?? false,
})))

watch(() => props.templateData, (val) => {
  let config: any = null
  if (val?.configJson) {
    try { config = typeof val.configJson === 'string' ? JSON.parse(val.configJson) : val.configJson } catch { config = null }
  }
  const { renderMode, schemaVersion, landingBlocks, sideMenu, gates, ...others } = config || {}
  const rows = Array.isArray(landingBlocks) ? [...landingBlocks] : []
  rows.sort((a: any, b: any) => Number(a?.sortOrder ?? 0) - Number(b?.sortOrder ?? 0))
  // 只认枚举里的 key：历史脏数据或别人写进来的未知块直接忽略，
  // 否则保存时会把没人能渲染的东西一直带在骨架里
  const known = rows.filter((b: any) => b && BLOCK_DEFS.some(d => d.key === b.key)).map((b: any) => b.key)
  const nextOrder = [...new Set(known)]
  for (const d of BLOCK_DEFS) if (!nextOrder.includes(d.key)) nextOrder.push(d.key)
  order.value = nextOrder
  const nextBlocks: Record<string, boolean> = {}
  for (const b of rows) nextBlocks[b.key] = b.enabled !== false
  blocks.value = BLOCK_DEFS.reduce((acc, d) => ({ ...acc, [d.key]: nextBlocks[d.key] ?? acc[d.key] }),
    { antiFake: true, richtext: true, video: false, promoImages: false })
  rest.value = others
  form.value = {
    templateName: val?.templateName || '',
    templateType: val?.templateType || '落地页',
    backgroundImage: val?.backgroundImage || '',
    sideMenu: { enabled: true, display: 'float', showTraceDetail: true, showBottomEntry: true, ...(sideMenu || {}) },
    gates: { requireAntiFakeBeforeJump: false, ...(gates || {}) },
  }
}, { immediate: true })

async function uploadBackground(options: any) {
  try {
    const res: any = await uploadFile(options.file)
    form.value.backgroundImage = res.data?.url || ''
    ElMessage.success('背景图上传成功')
  } catch {
    // request 拦截器已处理错误提示
  }
}

async function handleSave() {
  if (!String(form.value.templateName || '').trim()) return ElMessage.warning('请输入模板名称')
  if (!SIDE_MENU_DISPLAYS.includes(form.value.sideMenu.display)) return ElMessage.warning('侧边栏显示方式只能是悬浮或直显')
  saving.value = true
  try {
    const config = {
      ...rest.value,
      renderMode: 'landing',
      schemaVersion: 2,
      landingBlocks: order.value.map((k, i) => ({
        key: k, name: BLOCK_DEFS.find(b => b.key === k)?.name || k, sortOrder: i, enabled: blocks.value[k] !== false,
      })),
      sideMenu: {
        enabled: !!form.value.sideMenu.enabled,
        display: form.value.sideMenu.display,
        showTraceDetail: form.value.sideMenu.showTraceDetail !== false,
        showBottomEntry: form.value.sideMenu.showBottomEntry !== false,
      },
      gates: { requireAntiFakeBeforeJump: !!form.value.gates.requireAntiFakeBeforeJump },
    }
    const data = {
      templateName: form.value.templateName,
      templateType: form.value.templateType,
      backgroundImage: form.value.backgroundImage || null,
      configJson: JSON.stringify(config),
    }
    if (props.templateData?.id) await updateTraceTemplate(props.templateData.id, data)
    else await createTraceTemplate(data)
    ElMessage.success('保存成功')
    emit('saved')
  } catch {
    // 后端 TemplateConfigReader.validate 的拒绝已由拦截器弹出原文
  } finally { saving.value = false }
}

const SIDE_MENU_DISPLAYS = ['float', 'inline']

function initSortable() {
  nextTick(() => {
    if (!listRef.value) return
    sortable?.destroy()
    sortable = new Sortable(listRef.value, {
      animation: 200, handle: '.db-drag',
      onEnd: (evt: any) => {
        if (evt.oldIndex === undefined || evt.newIndex === undefined) return
        const moved = order.value.splice(evt.oldIndex, 1)[0]
        order.value.splice(evt.newIndex, 0, moved)
      },
    })
  })
}

onMounted(initSortable)
onUnmounted(() => sortable?.destroy())
</script>
```

```vue
<script setup lang="ts">
import { ref, reactive, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import RichTextEditor from '@/components/RichTextEditor.vue'
import { getLandingContent, saveLandingBlock, getAssignedTemplates } from '@/api/enterprise'
import { uploadFile } from '@/api/common'

const templates = ref<any[]>([])
const templateId = ref<number | null>(null)
const blocks = ref<Array<{ key: string; name: string; sortOrder: number; enabled: boolean; content: string }>>([])
const draft = reactive<Record<string, string>>({})
const saving = ref('')

onMounted(async () => {
  try {
    // 按渲染模式判定而非 templateKey：落地页模板的 key 是 tpl_<时间戳>
    const t = await getAssignedTemplates()
    templates.value = (t.data || []).filter((x: any) => x.renderMode === 'landing')
    if (templates.value.length) {
      templateId.value = templates.value[0].id
      await loadData()
    }
  } catch {
    // fail-closed：接口异常时 templates 保持空数组，页面停在"尚未开通"而不是给一个点了就 500 的表单
    templates.value = []
  }
})

async function loadData() {
  if (!templateId.value) return
  const res: any = await getLandingContent(templateId.value)
  blocks.value = res.data || []
  for (const b of blocks.value) draft[b.key] = b.content || ''
}

function images(key: string): string[] {
  try {
    const v = JSON.parse(draft[key] || '[]')
    return Array.isArray(v) ? v.filter(Boolean) : []
  } catch { return [] }
}

function filled(b: any) {
  if (b.key === 'promoImages') return images(b.key).length > 0
  return !!String(draft[b.key] || '').trim()
}

function revert(b: any) { draft[b.key] = b.content || '' }

async function uploadRichImage(file: File): Promise<string> {
  const res: any = await uploadFile(file)
  return res.data?.url || ''
}

async function addImage(key: string, file: any) {
  try {
    const list = images(key)
    const res: any = await uploadFile(file.raw)
    const url = res.data?.url
    if (!url) return ElMessage.error('上传失败')
    draft[key] = JSON.stringify([...list, url])
  } catch {
    // request 拦截器已处理错误提示
  }
}

function removeImage(key: string, i: number) {
  draft[key] = JSON.stringify(images(key).filter((_, idx) => idx !== i))
}

async function save(b: any) {
  if (!templateId.value) return
  saving.value = b.key
  try {
    await saveLandingBlock(templateId.value, b.key, draft[b.key] || '')
    ElMessage.success('保存成功')
    await loadData()
  } catch {
    // request 拦截器已处理错误提示
  } finally { saving.value = '' }
}
</script>
```
